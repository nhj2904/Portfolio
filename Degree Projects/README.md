# Degree Projects

Projects completed during my Bachelor of Science (Hons) in Statistical Data Science at Heriot-Watt University Malaysia.

These projects cover statistical modelling, computational methods, machine learning and data analysis techniques developed throughout my degree studies.

| Project | Course | Date | Languages Used | About the Project | What I Did |
|---|---|---|---|---|---|
| [Bayesian Inference and Gibbs Sampling](Bayesian%20Inference%20and%20Gibbs%20Sampling) | F79BI Bayesian Inference and Computational Methods | March 2026 | R | Applied Bayesian inference and Markov Chain Monte Carlo (MCMC) methods to analyse component reliability using lifetime data from two lightbulb manufacturers. A Gibbs sampling algorithm was implemented to estimate unknown parameters and analyse posterior distributions. | Derived joint and conditional posterior distributions, implemented a Gibbs sampler with Gamma conditional distributions, generated posterior samples using 100,000 MCMC iterations with burn-in and thinning, evaluated convergence using trace plots and autocorrelation analysis, and compared posterior lifetime distributions between manufacturers. |
| [Statistical Modelling of Mobile Networks and Bike Rental Demand](Statistical%20Modelling%20of%20Mobile%20Networks%20and%20Bike%20Rental%20Demand) | F79MB Statistical Models B | March 2026 - April 2026 | R | Applied statistical modelling techniques to analyse count data and investigate factors influencing demand patterns in mobile networks and bike rental datasets. | Performed exploratory analysis, fitted regression models including Poisson and Negative Binomial models, evaluated model assumptions, analysed residuals and compared model performance. |
| [Survival Models and Mortality Graduation Using Poisson GLMs](Survival%20Models%20and%20Mortality%20Graduation%20Using%20Poisson%20GLMs) | F79SU Survival Models | March 2026 | R | Applied survival modelling techniques to mortality data using Poisson Generalised Linear Models (GLMs). Different mortality graduation models were developed and compared using statistical diagnostics. | Fitted Gompertz, quadratic and cubic mortality models, analysed Pearson residuals, performed goodness-of-fit evaluation and compared models using Akaike Information Criterion (AIC). |
| [Statistical Modelling of Software Bugs and Mobile App Usage](Statistical%20Modelling%20of%20Software%20Bugs%20and%20Mobile%20App%20Usage) | F79MB Statistical Models B | February 2026 | R | Analysed software bug resolution times and mobile application session durations using statistical modelling and resampling methods. | Applied lognormal modelling, maximum likelihood estimation, goodness-of-fit analysis, bootstrap confidence intervals and simulation-based hypothesis testing. |
| [Essay Score Prediction with Supervised Machine Learning](Essay%20Score%20Prediction%20with%20Supervised%20Machine%20Learning) | F78DS Data Science Life Cycle | March 2025 - April 2025 | Python | Developed a supervised machine learning pipeline to predict essay scores using linguistic features extracted from written responses. This project was completed as part of the F78DS in-course Kaggle competition. | Performed exploratory data analysis, feature analysis, preprocessing, model training using Gaussian Naive Bayes and Random Forest, and evaluated models using Quadratic Weighted Kappa (QWK), accuracy and F1-score. Achieved 4th place on the competition leaderboard. |
| [ANOVA and Principal Component Analysis](ANOVA%20and%20Principal%20Component%20Analysis) | F79PS Further Statistical Methods | March 2025 | SPSS, R, Python | Applied statistical techniques to analyse experimental data, investigate differences between groups and identify important patterns using dimensionality reduction methods. | Conducted ANOVA testing, performed post-hoc analysis, applied Principal Component Analysis (PCA), interpreted statistical outputs and visualised findings. |
| [Bayesian Estimation and Predictive Modelling](Bayesian%20Estimation%20and%20Predictive%20Modelling) | F79BI Bayesian Inference and Computational Methods | November 2024 | R | Applied Bayesian and classical statistical methods to analyse the lifetime of drilling machine components using the Maxwell distribution in a reliability modelling scenario. | Implemented Bayesian estimation methods, performed simulation-based inference, compared estimation approaches, and applied predictive modelling techniques for reliability analysis. |
| [Maximum Likelihood Estimation with R Simulation](Maximum%20Likelihood%20Estimation%20with%20R%20Simulation) | F79MA Statistical Models A | October 2024 | R | Investigated the behaviour and performance of maximum likelihood estimators through mathematical derivations and simulation-based analysis. Estimation accuracy was evaluated under different sample sizes using an insurance modelling scenario. | Derived likelihood-based estimators and theoretical properties, developed R simulations, analysed bias, variance and mean squared error, and visualised simulation results. |
