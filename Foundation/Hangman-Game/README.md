# Hangman Game

A console-based Java Hangman game developed as a foundation group project at Heriot-Watt University Malaysia.

| Detail | Information |
|---|---|
| Date | November 2022 |
| Course | K16SO Object-Oriented Programming |
| Language | Java |
| Libraries and Tools | Java standard library (ArrayList, Scanner, Random, SimpleDateFormat, Date), Eclipse IDE |

## About the Project

Players guess letters to uncover a randomly selected word, with up to six incorrect guesses per round. Correct guesses reveal letters, while incorrect guesses add body parts to the hangman figure. The game uses coloured console output and allows players to continue or quit after each round.

## My Contribution

- Created the Record class to collect the player's name and student ID.
- Implemented the display of player details and the time each round ended.
- Used ANSI colour codes to format input prompts and displayed details.

## Skills Demonstrated

- Creating a Java class with fields, a constructor and methods.

- Formatting and displaying the current time.
