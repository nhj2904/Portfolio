# Foundation Projects

Projects completed during my Foundation studies at Heriot-Watt University Malaysia.

These projects introduced fundamental programming concepts, software development practices and web application development through Java, web technologies and database integration.

| Project | Course | Date | Languages Used | About the Project | My Contribution |
|---|---|---|---|---|---|
| [HappyU Met Gala Dinner Website](HappyU%20Met%20Gala%20Dinner%20Website) | K16SO Object-Oriented Programming | June 2023 | HTML, CSS, JavaScript, PHP, SQL | A Bridgerton-themed event website developed for HappyU’s Gala Dinner, featuring event information, guest registration, payment details, an itinerary page and database integration for storing participant information. | Contributed to the website design, created the About Us and administrator login pages, and implemented itinerary features including video integration and a horizontally scrollable food menu. |
| [HappyU Farm GUI Application](HappyU%20Farm%20GUI%20Application) | K17SD Data Structures and Software Design | March 2023 | Java | An interactive graphical farm application where users can add drawn animals into a farm scene and interact with them through mouse dragging functionality. | Designed and programmed the sheep character, contributed to the background design and supported the development and testing of the application. |
| [Hangman Game](Hangman%20Game) | K16SO Object-Oriented Programming | November 2022 | Java | A console-based word guessing game featuring random word selection, limited incorrect attempts, coloured console output and replay functionality. | Created the Record class to collect and display player information, including player details and the completion time of each game round. |
